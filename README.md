## Project case studies

### 🅰️ AR Room Planner — Unity, C#, AR Foundation, Google Cloud Storage
An Android AR app that lets you place, rotate, scale, and delete furniture in your real room using plane detection and spatial mapping. Room layouts are serialized to JSON and synced to Google Cloud Storage, so a saved layout can be reconstructed in a later session.

Built from scratch with zero prior Unity or AR experience, for a Mixed Reality and Metaverse course — the hard part wasn't the UI, it was getting stable plane tracking and gesture-based object manipulation working reliably on a mid-range Android device.

**Repo:** [`AR-Room-Planner`](https://github.com/devExponent/AR-Room-Planner)

### 🎓 ScholarJoint — Vite, React, TypeScript, Tailwind, Radix UI
A role-based academic conference and journal management platform with separate dashboards for Authors, Reviewers, and Admins — covering submission, review assignment, and publication workflows.

Frontend-only build with a mock service layer that persists to `localStorage`, shadcn/ui-style components on top of Radix primitives, and a custom design token system tuned for an academic/editorial look rather than a generic SaaS theme.

**Repo:** [`ScholarJoint`](https://github.com/devExponent/ScholarJoint)

### 🌍 EarthAngels Finland Event Management System — React, TypeScript, Tailwind, Spring Boot, MySQL
Full-stack event management system for a multicultural community organization in Finland. React/TypeScript frontend with role-based access control for admins vs. volunteers, backed by a Spring Boot REST API using JPA/Hibernate for event creation and registration approval.

**Repo:** [`EarthAngelsFinland`](https://github.com/devExponent/EarthAngelsFinland)

### 🚌 CTMIS — React, Firebase
Intercity transport booking platform: user registration, ride booking, and booking management on top of Firebase.

**Repo:** [`CTMIS`](https://github.com/devExponent/CTMIS)
